# 第一章 认识 OpenClaw

用过 ChatGPT 或 Claude 的读者，大多对大语言模型的能力印象深刻；但要让它们把一件事完整做完（比如自动查收邮件、整理数据并发送到飞书群），还缺一个把 AI 与真实软件连接起来的系统框架。

**[OpenClaw](https://openclaw.ai/) 是一个将大语言模型与真实世界连接起来、让 AI 替你自动且安全地完成复杂任务的智能体项目。**

本章以应用为先：先介绍 OpenClaw 能做什么、适合谁用、与已有工具有何区别，再用一张图和一张表建立核心概念。技术细节留到后续章节展开。

1. **说清楚 OpenClaw 是什么**：能向别人解释它解决了什么问题，适合什么场景。
